# Итоговый проект "TODO manager"

## Описание
Это итоговый проект по курсу Go для начинающих. Требуется выполнить задание на создание веб приложения управления задачами.

## Что было выполнено из заданий с повышеной трудностью
* Разбор переменных окружения для имения BD файла и номера порта сервера

## Локальный запуск
Для запуска локально, достаточно выполнить команду корневой директории проекта: go run cmd/main.go
Порт сервера, по умолчанию: 7540
При желаении указать другой номер порта, перед запуском можно определить переменную окружения "TODO_PORT": export TODO_PORT=<NUMBER>
Так же можно указать порт вместе с командой запуска: TODO_PORT=<NUMBER> go run cmd/main.go
Сервер в лог консоли напишет, какой порт используется.

Имя файла BD по умолчанию: scheduler.db
При желании, возможно указать другое имя, через переменную окружения "TODO_DBFILE": export TODO_DBFILE=newfilename.db

## Тесты и фронтенд
В директории `tests` находятся тесты для проверки API.

Директория `web` содержит файлы фронтенда.

### Запуск тестов
Для запуска всех базовых тестов достаточно выполнить команду из корня проекта: go test ./tests
